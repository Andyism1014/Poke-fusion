# 体验（UX）审查与优化记录

以"现代玩家第一次玩这个改版"为视角，逐条列出原版或早期版本里麻烦、看不懂的地方，以及对应的处理。

## 已解决

| 麻烦的点 | 处理 |
| --- | --- |
| 被动只能去终端"鉴定"才看得到 | 摘要画面 Info 页：有被动时特性栏右侧显示 SELECT 图标和"+N"；按 SELECT 依次切换"主特性 → 被动 1/2/3"，同时显示对应说明。切换宝可梦或翻页后回到主特性。 |
| 出招时不知道哪招有效 | 选招时招式名按对当前对手的效果着色：效果拔群为绿，效果不好为红，无效为灰。判断会算上第三属性、漂浮类被动和太晶化。 |
| 看不到对手的属性，尤其是第三属性 | 属性图标常驻显示，第三属性占第三个图标位。 |
| 抓完不知道是不是好材料 | "抓到了！"之后紧接着一条鉴定，每条信息一行：IV 总和、稀有标记、各个被动、第三属性。 |
| 炼妖结果不透明，按下去才知道 | 先显示预览卡（子代的等级、物种、IV、特性、被动池、招式池和第三属性分别怎么继承、概率多少），再弹确认；完成后有音效和结果卡。 |
| 第一次打开终端不知道能干什么 | 首次打开时有一段简短引导，之后不再出现。 |
| 挑材料要在箱子之间来回翻 | 选择器：5 行列表加 3 行信息栏（特性、属性、被动），L/R 切换箱子，SELECT 按 IV 排序，并记住上次的位置。 |
| 换队员、存放宝可梦要跑回宝可梦中心 | 开局就送 Box Link（随身电脑）和 Fusion Terminal，可以直接用任何箱子里的宝可梦当材料。 |
| 前期练级、找宝可梦太磨人 | 开局就有跑鞋、学习装置（全队得经验，可在设置里关）和 DexNav；捕获模式可选 Classic / Convenient / Material。 |
| 对话太慢、反复弹出道具说明 | 默认文字速度为快；捡到道具的说明只在第一次出现；驱虫剂用完会提示是否再用一个。 |
| 个体值只有字母评价 | 摘要页显示精确的 IV/EV 数值。 |
| 忘掉的招式找不回来 | 开启招式回忆（蛋招式、招式学习器、教学招式）。 |
| 设置分散在各处 | 捕获模式、学习装置、野生宝可梦（全世代 / 原版）都集中在终端的 Settings 里，每项都有一句说明。 |
| 转生带来的队伍在拿到御三家前打不开 | 只要队伍不为空，起始菜单就显示"宝可梦"。 |
| 只有英文，看不懂特性说明 | 另出简体中文版（`make chinese`），和英文版同时存在；宝可梦、招式、特性、道具用官方译名，剧情和界面全部汉化；特性说明重写成能力页一行放得下的短句。 |
| 后期没东西玩 | 炼妖塔（无尽挑战）、碎片商店、转生（New Game+），详见 ROADMAP。 |

## 审美上的调整

- 终端的信息全部改成"卡片"：统一边框和固定排版，左边是名字和等级，右边是世代；IV 六项排在一行，下面依次是属性、特性、被动。
- 确认框紧贴在卡片右下角，不再盖住卡片内容。
- 招式着色只用调色板里的空闲色（5~8 号），保持原版对话框的风格。
- 摘要画面里被动标签用青色，与主特性的颜色区分开。

## 有意不改的

- 战斗动画：保留原版默认，可在 Options 里关闭（Battle Scene: Off）。

## 后续可以考虑

- 炼妖预览里直接标出"可能继承的招式"。
